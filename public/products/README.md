# Product images

Drop your own product photos in this folder. Reference them in
`app/products/page.tsx` (the `PRODUCTS` / `CATEGORIES` arrays) as
`/products/<filename>` — e.g. `img: "/products/hoodie-heavyweight-01.jpg"`.

## Image guidelines (to match the existing layout)

- **Aspect ratio:** portrait **3:4** (cards use `aspect-[3/4]`). A square also works
  for the quick-view modal, but 3:4 looks best in the grid.
- **Size:** ~900 × 1200 px is plenty. Keep each file under ~300 KB.
- **Format:** `.webp` (best) or `.jpg`.
- **Naming:** lowercase, hyphenated, category-prefixed, e.g.
  `tee-vintage-washed-01.jpg`, `hoodie-drop-shoulder-01.webp`, `cargo-utility-01.jpg`.

## Per-product info I need (besides the photo)

For each product, send me: name, category, fabric, GSM/weight, price/pc, MOQ,
lead time, a 1-line description, and optionally a badge (`Best Seller` / `New` / ...).

Category photos (one per category) follow the same rules.
